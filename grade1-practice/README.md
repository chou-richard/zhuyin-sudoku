# 一年級上學期國語數學線上題庫

這是純靜態網站，可在手機、平板與電腦使用。

- 國語題庫：500 題
- 數學題庫：500 題
- 總題數：1,000 題

## 使用方式

1. 本機預覽：直接開啟 `index.html`。
2. 正式線上版：將本資料夾上傳至 GitHub Pages 或其他靜態網站空間。
3. 題庫、作答、批改與進度記錄都在瀏覽器端執行，不需要後端伺服器。

## 內容原則

- 單元範圍參考使用者指定的一年級上學期教材與常見教學目標。
- 題庫文案為重新原創，沒有複製出版社考卷題目。
- 語音朗讀使用裝置的 `zh-TW` 系統語音；可用語音會依手機或平板而不同。
