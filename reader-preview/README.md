# 小太陽閱讀花園 · 介面預覽

[開啟預覽](https://chou-richard.github.io/zhuyin-sudoku/reader-preview/)

適合國小低年級、手機及平板操作的注音閱讀器。

- 故事森林：已提供 100 則低年級故事。
- 科學探索：已提供 100 則科學小常識。
- 童謠小屋：已提供 100 則原創兒童歌詞。
- 閱讀標題和內文採直式排版，文字由上往下、欄位由右往左，並可切換「純注音／國字＋注音」。
- 純注音模式把聲調放在韻母旁邊，輕聲點放在音節右上。
- 字級調整、翻頁、搜尋、收藏及已讀紀錄。
- 3 張 GPT 生成主題插畫，預覽中同類篇章共用插畫。
- 台灣中文語音選擇器只列出裝置提供的 `zh-TW` 聲音，並記住選擇；朗讀速度可選 `0.25×`、`0.5×`、`0.75×`、`1×`。實際聲音依瀏覽器及裝置語音而定。兒童歌詞目前為原創文字，沒有作曲或演唱錄音。

本版已上架 300 篇互動內容。收藏及閱讀紀錄只儲存在目前瀏覽器；不需登入。文字已通過自動化格式與注音字數檢查，台灣讀音、多音字與專屬插圖仍會持續人工優化。

以靜態 HTML、CSS、JavaScript 製作，可直接部署 GitHub Pages。2026-10-11。
