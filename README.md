# 注音數獨島

適合平板操作的繁體中文注音學習遊戲，包含：

- 初級 4×4 注音數獨
- 中級 6×6 注音數獨
- 初級 30 題、中級 21 題，兩個難度各自完整涵蓋 37 個注音
- 37 個注音符號皆可點按播放教育部標準發音
- 100 題看圖連線結合韻（25 回合）
- 100 張 GPT 原創題圖
- 指定的輕快背景音樂循環播放，並內嵌互動音效
- 明顯的「← 主選單／← 返回」觸控按鈕
- 不必先解完即可按「⏭ 換一題」輪替題庫

遊戲核心為單一 `index.html`，題圖、介面美術與音樂均已內嵌。公開版僅額外載入 Cloudflare Web Analytics 匿名統計程式；統計程式載入失敗不影響遊戲。

## 隱私與統計

- 公開版以 Cloudflare Web Analytics 收集匿名彙總的頁面瀏覽量、來源、裝置類型與網頁效能資料。
- 不使用 Cookie、不使用 localStorage 追蹤、不建立使用者指紋，也不識別個別兒童或玩家。
- 單機版不載入任何分析程式，可完全離線使用。
- 統計資料只在網站擁有者的 Cloudflare 儀表板查看，遊戲頁面不顯示個人訪客紀錄。

## 操作

直接開啟 GitHub Pages 網址，選擇遊戲模式即可。行動瀏覽器的音樂需要先點擊開始或音樂按鈕，才會依瀏覽器規範播放。

數獨模式可點棋盤格、注音鍵或既有注音重聽發音；支援方向鍵移動、對話框 Escape／Tab 操作、瀏覽器縮放及無法使用 localStorage 時的備援。

## 驗收

- 100 題、100 個唯一題目與圖檔
- 注音數獨 51 題皆為唯一解
- 初級與中級各自涵蓋 37 音，並內嵌 37 段點讀 MP3
- 20 組結合韻，每組 5 題
- 25 回合，每回合 4 個不同答案
- 瀏覽器逐題完成 100/100
- 1024×768、834×1194 與 390×844 響應式瀏覽器測試通過
- HTML 內建自我檢查：`passed`
