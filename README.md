# 注音數獨島

適合平板操作的繁體中文注音學習遊戲，包含：

- 初級 4×4 注音數獨
- 中級 6×6 注音數獨
- 100 題看圖連線結合韻（25 回合）
- 100 張 GPT 原創題圖
- 內嵌輕快背景音樂與互動音效
- 明顯的「← 主選單／← 返回」觸控按鈕

遊戲為單一 `index.html`，題圖、介面美術與音樂均已內嵌，不使用外部 CDN。

## 操作

直接開啟 GitHub Pages 網址，選擇遊戲模式即可。行動瀏覽器的音樂需要先點擊開始或音樂按鈕，才會依瀏覽器規範播放。

## 驗收

- 100 題、100 個唯一題目與圖檔
- 20 組結合韻，每組 5 題
- 25 回合，每回合 4 個不同答案
- 瀏覽器逐題完成 100/100
- 1024×768 平板橫向與 390×844 窄版直向通過
- HTML 內建自我檢查：`passed`
